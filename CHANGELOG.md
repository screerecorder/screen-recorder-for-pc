# Changelog

All notable changes to Aura — Screen Recorder for PC — are documented here.

## [1.0.0] — 2026-10-08

### Initial release

- **Full desktop capture** — record the complete Windows desktop, File Explorer, and system dialogs on Windows 10 and 11
- **Window capture** — record any individual application window
- **Region capture** — drag a custom frame around any area; live pixel-size readout before recording starts
- **System audio + microphone** — recorded as separate tracks for independent mixing in post
- **Hardware encoding** — NVIDIA NVENC, AMD AMF, and Intel Quick Sync support; CPU overhead below 5% at 1080p 60FPS
- **Up to 4K at 60 FPS** — supports 720p, 1080p, 1440p, and 2160p at 30 or 60 frames per second
- **Floating record dock** — always-visible timer, live stereo audio meters, and one-click mic/camera toggles
- **Built-in library** — search, star, and preview recordings with resolution, FPS, and file size at a glance
- **Built-in trimming** — cut dead time at the start and end without a separate video editor
- **Export presets** — YouTube 4K, Web 1080p, and Discord 25 MB presets; MP4 (H.264 + AAC) and MKV output
- **No watermark** — free with no branding on exported recordings
- **No time limit** — record as long as disk space allows
- **Windows 10 and 11** — compatible with both operating systems; no additional runtime required
